# Final Processed Dataset / Features

`final_processed_data.csv` is generated by running `group_pipeline.ipynb` end to end
(the last cell writes it here automatically). It is not pre-generated in this folder
because producing it requires downloading the raw dataset from Kaggle at runtime via
`kagglehub`, which needs Kaggle API access.

To generate it yourself:

```bash
jupyter nbconvert --to notebook --execute group_pipeline.ipynb
```

or simply open `group_pipeline.ipynb` and run all cells — the final cell saves the
processed dataset to `results/outputs/final_processed_data.csv`.
